# vrok Homebrew tap

Homebrew cask for [vrok](https://github.com/AliJabbar034/vrok): share files,
folders and localhost through a temporary URL, straight from your machine. No
upload, no account, and the link expires.

## Install

```sh
brew install --cask AliJabbar034/tap/vrok
```

Works on macOS (Apple silicon and Intel) and Linux. Shell completions for zsh,
bash and fish are installed too.

## Update

```sh
brew upgrade --cask AliJabbar034/tap/vrok
```

## Uninstall

```sh
brew uninstall --cask vrok
```

## About this repository

The cask in `Casks/vrok.rb` is generated by the vrok release workflow on every
release. Do not edit it by hand: changes are overwritten. Report problems, ask
questions or contribute in the main repository:
[AliJabbar034/vrok](https://github.com/AliJabbar034/vrok/issues).

- Website: <https://alijabbar034.github.io/vrok/>
